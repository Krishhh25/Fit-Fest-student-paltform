# Scout

Scout is a student opportunity platform that helps students find internships, hackathons, scholarships, courses, workshops, certifications and competitions in one place.

## Features

• Search opportunities by title or skill  
• Filter by category  
• Sort by deadline, title or recommendation  
• Personalized recommendations based on skills and interests  
• Bookmark opportunities  
• Student profile with education, skills, interests and location  
• Login and signup with Supabase  
• Profile and bookmarks saved to Supabase
