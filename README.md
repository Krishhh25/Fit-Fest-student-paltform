# Scout — Student Opportunity Discovery Platform

Find opportunities. Build your future.
This project was built for Fit-Fest Hackathon,2026 and is up for evaluation.
Scout is a student opportunity platform that helps students find internships, hackathons, scholarships, courses, workshops, certifications and competitions in one place.

## The Problem

Students today miss out on opportunities not because they aren't capable, but because information is scattered across college groups, social media and separate niche platforms. Searching takes time, relevant opportunities are easy to miss, and deadlines slip by unnoticed.

## The Solution

Scout brings every opportunity type into a single platform where students can search, filter, get matched to relevant opportunities and save them for later, all from one profile.

## Features

| Feature | Description |
|---|---|
| Search    | Search opportunities by title or skill |
| Filter    | Filter opportunities by category |
| Sort      | Sort by deadline, title or recommendation |
| Personalized Recommendations | Suggestions based on the student's skills and interests |
| Bookmarks | Save opportunities to revisit later |
| Student Profile | Education, skills, interests and location |
| Authentication | Login and signup with Supabase |
| Data Persistence | Profile and bookmarks saved to Supabase |

## Technologies Used

| Layer | Tech |
|---|---|
| Frontend | HTML, CSS, JavaScript |

## Getting Started

### Prerequisites

* A modern web browser
* A free Supabase account (for your own backend instance)

### Setup & Run

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/scout.git
cd scout

# 2. Add your Supabase project credentials
# Create a .env file (or config file) with:
SUPABASE_URL=your-supabase-url
SUPABASE_ANON_KEY=your-supabase-anon-key

# 3. Run the project locally
# Open index.html in your browser, or serve the folder with a local server
```
